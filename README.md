# Bac Bo Signal Analyzer

Aplicativo web leve para registrar resultados de Bac Bo e analisar estatísticas do histórico informado.

## Primeira versão

- Registro de Player, Banker e Empate
- Histórico das rodadas
- Contagens e percentuais
- Sequências e padrões recentes
- Análise estatística transparente
- Persistência local no navegador
- Interface responsiva
- Estrutura preparada para futura transformação em PWA/WebView

> Importante: o projeto é uma ferramenta estatística. As análises não garantem resultados futuros nem prometem taxa fixa de acerto.

## Como executar

Abra o arquivo `index.html` em um navegador moderno.
